# Задание 5. Проектирование технологического стека и расчёт стоимости

Задание: спроектировать технологический ландшафт, выполнить стоимостной анализ и построить роадмап внедрения Data Mesh.

## Состав артефактов

| Файл                                   | Содержание                                                                                                                     |
|----------------------------------------|--------------------------------------------------------------------------------------------------------------------------------|
| [`tech-radar.md`](./tech-radar.md)     | Расширенный технический радар: технологии и архитектурные паттерны со статусами **Adopt / Trial / Assess / Hold**.             |
| [`tco-analysis.md`](./tco-analysis.md) | TCO-модель «текущая vs целевая» на горизонте 3 лет: статьи затрат, дельта, точка окупаемости.                                  |
| [`roadmap.md`](./roadmap.md)           | Стратегический роадмап Data Mesh: роли, этапы (пилот → масштабирование → поддержка), привязка к бизнес-целям, диаграмма Ганта. |

## Краткие выводы

- **Технологический радар.** Ядро целевой платформы (Event-Driven Architecture, Kafka, Schema Registry, IaC) - **Adopt**; элементы Data Mesh (Data Mesh, Self-service BI, Lakehouse, CDC) - **Trial**; Event Sourcing, CQRS, Trino - **Assess**; весь легаси (DWH SQL Server 2008, PowerBuilder, синхронный Camel) - **Hold**.
- **TCO.** На 3-летнем горизонте целевая архитектура дешевле в сумме (~550 млн ₽ против ~592 млн ₽) и существенно дешевле к 3-му году (132 против 215). Год 1 - инвестиционный, окупаемость наступает в течение 2-го года.
- **Роадмап.** Три этапа (0–6 / 6–18 / 18–36 месяцев) синхронизированы с дорожной картой компании. Определены ключевые роли (Data Product Owner, Data Engineer, BI-аналитик, Platform Team), критерии перехода между этапами и привязка к бизнес-целям (промежуточное состояние, финальное состояние, долгосрочная цель).
